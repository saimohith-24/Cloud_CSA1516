Cloud Computing Concepts & SaaS Architecture

Explanation of cloud service models, SaaS demonstration features, and viva viva presentation guide.

Current Architecture

SaaS (Software as a Service)

Definition: Fully managed application hosted on cloud infrastructure and accessed by end users via web browser.

  • User manages: Nothing! Only uses the web application.
  • Cloud Provider manages: Application, data, runtime, OS, server hardware.
  • Project Example: This Hostel Complaint System allows students and wardens to access the service directly without installing servers.

PaaS (Platform as a Service)

Definition: Cloud platform providing runtimes, frameworks, and deployment engines for developers.

  • User manages: Application code and data databases.
  • Cloud Provider manages: OS, server runtime, scaling, network hardware.
  • Examples: Google App Engine, Heroku, Firebase App Hosting.

IaaS (Infrastructure as a Service)

Definition: Virtualized computing resources (VMs, storage, firewalls) provided over the internet.

  • User manages: OS, middleware, runtime, app code, data security.
  • Cloud Provider manages: Physical servers, virtualizers, data centers.
  • Examples: AWS EC2, Google Compute Engine (GCE), Azure VMs.
